# 📦 Telegram + МойСклад Automation

**Автоматизация процесса оприходования товаров между складами.**

### Бизнес-задача:
Сократить ручной ввод данных логистом и уменьшить количество ошибок.

### Процесс:
1. Логист отправляет фото накладной в Telegram.
2. Computer Vision распознаёт данные документа.
3. Workflow обрабатывает информацию.
4. Данные передаются в систему МойСклад.

Результат:
- меньше ручной работы;
- ускорение обработки документов;
- снижение количества ошибок при вводе.
