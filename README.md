# 🤖 AI Automation Workflows Portfolio

Коллекция готовых AI-агентов и автоматизационных workflow, созданных в **n8n** и **Make**.

В репозитории представлены практические решения для бизнеса: AI-консультанты, RAG-агенты, интеграции с CRM, автоматизация продаж, анализ звонков и персональные помощники.

Проекты демонстрируют навыки построения:

* AI-агентов с собственной базой знаний;
* RAG-систем с векторными базами данных;
* бизнес-автоматизаций через n8n;
* интеграций с внешними сервисами;
* процессов продаж и аналитики.

## 🚀 Реализованные проекты

### 🧠 AI Consultant для турагентства

AI-консультант, который помогает клиентам подобрать путешествия, отвечает на вопросы и автоматизирует первичную коммуникацию с потенциальными клиентами. Реализован на основе бота в Telehram канале, отвечает на вопросы про путешествия, в зависимости от предпочтений клиента, рекомендует страну. В качестве первой фразы рандомно выдает любопытный факт о какой-либо стране. В качестве бонуса во время паузы между ответами, в чате виднеется гифка с морем и закатом.

### 📞 SWOT-анализ телефонных звонков

Workflow для анализа разговоров с клиентами и формирования SWOT-анализа:

* выявление сильных и слабых сторон коммуникации;
* поиск точек улучшения продаж;
* анализ качества работы менеджеров.

Работает после загрузки в него аудиозаписи звонка. После оцифровки разговора нейросеть с инструкциями оценивает менеджера по заданным критериям, дает рекомендации. Путь вхождения файла может быть быстро изменен, что позволит подстроить воркфлоу под инфраструктуру компании.

### 🔎 RAG AI Agent с векторной базой данных

AI-агент с собственной базой знаний.

Возможности:

* загрузка документов;
* поиск релевантной информации через embeddings;
* генерация ответов на основе внутренних данных.

База знаний обновляется через добавление новых файлов на гугл диск, что является очень удобным для обновления знаний агента.

### 👨‍💼 Экзаменация кандидатов (без ИИ)
Каждый знает, что сложная автоматизация стабильней AI агента. Автоматизация была разработана в рамаках онбординга. Новые сотрудники после изучения регламентов работы компании, были протестированы. В тестировании использовалась БД с открытыми и закрытыми вопросами. Настроена валидация закрытых вопросов. Тестирование развернуто на бызе Slack, как основного инструмента взаимодействия сотрудников внутри компании. Настроены уведомления сотрудникам, не прошедшим тестирование и HR, для контроля. Настроены сроки хранения результатов тестирования. На HR выведен аппрув с результатами тестирования, потому, что открытые вопросу подлежат анализу и заказчик оставил за собой право их смотреть (хатя это можно возложить на AI агента).

Автоматизированный процесс оценки кандидатов:

* проведение тестирования;
* сбор результатов;
* обработка данных;
* подготовка итоговой информации для HR.

### 📦 n8n + Telegram + МойСклад

Интеграция для автоматизации бизнес-процессов:

* взаимодействие через Telegram;
* работа с данными из МойСклад;
* автоматизация сделана в помощь логисту, который управлял оприходованием между складами.

Суть автоматизации: логисту скидывают в ТГ фото накладных → он отправляет их в бота → (в бота встроено компьютерное зрение от chatGPT) он читает накладную и отправляет запрос в сервисе МойСклад.

## 🛠 Технологии

### ⚙️ Automation Platforms
* **n8n / Make / Workato / Zapier** — разработка и автоматизация workflow-процессов, интеграция сервисов и построение бизнес-автоматизаций

### 🤖 AI & Knowledge Systems
* **LLM / AI Agents** — создание интеллектуальных ассистентов и AI-агентов для бизнес-задач
* **RAG (Retrieval-Augmented Generation)** — построение AI-систем с собственной базой знаний
* **Vector Databases** — семантический поиск и работа с векторными представлениями данных

### 🔗 API & Integrations
* **REST API / API Integration / Postman** — подключение внешних сервисов, работа с API и тестирование интеграций
* **Webhooks** — создание событийных интеграций и автоматических сценариев

### 🗄 Data & Business Tools
* **Airtable / Baserow** — создание структурированных баз данных и внутренних бизнес-инструментов
* **Softr** — разработка клиентских порталов и интерфейсов поверх баз данных
* **CRM / ERP Integrations** — автоматизация процессов продаж, управления клиентами и обмена данными
