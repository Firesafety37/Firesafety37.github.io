Политика конфиденциальности Hermes assistant

Дата обновления: 09.09.2026

Hermes assistant — персональный AI-ассистент Тараса Воронцова для работы с Google Workspace и автоматизациями. Приложение используется для личных и рабочих сценариев владельца аккаунта.

Какие данные обрабатываются

Приложение может получать доступ к данным Google Workspace только после явного разрешения пользователя через OAuth: файлам Google Drive, документам, таблицам, календарю, контактам и письмам Gmail в рамках выданных разрешений.

Как используются данные

Данные используются только для выполнения команд пользователя: загрузки и публикации файлов, чтения и обновления таблиц, работы с документами, календарём и почтой, а также для автоматизации бизнес-процессов.

Передача данных третьим лицам

Данные Google Workspace не продаются и не передаются третьим лицам. Доступ используется только для выполнения действий, запрошенных пользователем.

Хранение данных

OAuth-токены хранятся на сервере пользователя и применяются для авторизованных запросов к Google API. Файлы и результаты обработки сохраняются только там, где это указано пользователем: в Google Drive, Google Sheets, локальном хранилище или подключённых сервисах.

Безопасность

Доступ к Google API ограничен выданными OAuth-разрешениями. Пользователь может отозвать доступ в настройках Google Account → Security → Third-party access.
